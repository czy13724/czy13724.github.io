## 什么是 GitHub 学生开发者权益包？

GitHub Student Developer Pack 是目前对计算机专业学生价值最高的福利之一。它不仅包含 GitHub Copilot 免费使用权，还赠送：
*   **JetBrains 全家桶**（IntelliJ IDEA, PyCharm 等）
*   **DigitalOcean** $200 云服务器信用额度
*   **Namecheap** 免费域名与 SSL 证书
*   **Microsoft Azure** 学生订阅
*   以及 Termius, Canva 等数十款开发工具的会员服务。

## 第一阶段：申请前的准备工作

为了提高通过率，请确保你准备好了以下材料。GitHub 现在不再信任单纯的 `.edu` 邮箱，**必须提供辅助证明材料**。

### 1. 必备硬件与环境
*   **设备**：建议使用电脑或带有高质量摄像头的手机。
*   **浏览器**：Chrome 或 Edge（关闭隐私模式，允许获取地理位置）。
*   **网络环境**：
    *   **关键点**：GitHub 会校验你的 **IP 地址** 与你学校的 **物理位置** 是否一致。
    *   如果你在校内，直接连接校园网（Wi-Fi）申请，通过率最高。
    *   如果你在家或使用代理工具，请确保你的 IP 显示位置尽可能接近你的学校城市，否则极易因 "Distance too far from campus" 被据。

### 2. 证明材料 (Proof of Academic Status)
仅有 EDU 邮箱是不够的，你需要上传带有**当前日期**的证明文件：
*   **学信网 (CHSI) 在籍证明**：下载英文版或带有翻译的截图（推荐）。
*   **学生证 (Student ID)**：必须清晰显示姓名、学校、**有效期**。
*   **录取通知书**：仅限新生。
*   **教务系统截图**：包含当前学期的课程表。

## 第二阶段：详细申请流程

### 步骤 1：完善 GitHub 个人资料
在申请前，进入 [GitHub Profile Settings](https://github.com/settings/profile)：
1.  **Name**: 填写真实姓名（拼音），必须与学生证上的名字一致。
2.  **Bio**: 简单写一句 Student at [University Name]。
3.  **Public Email**: 设置为你的学校 EDU 邮箱。
4.  取消勾选 "Private contributions" 以展示你的活跃度（加分项）。

### 步骤 2：进入申请页面
访问 [https://education.github.com/benefits](https://education.github.com/benefits) 并登录。
选择 **"Get student benefits"**。

### 步骤 3：填写表单与验证邮箱
1.  选择你的 EDU 邮箱。
2.  输入学校的英文全称。
3.  **How do you plan to use GitHub?**：这里认真填写 2-3 句话。
    *   *范例：I plan to use GitHub to host my coursework projects, collaborate with classmates on assignments, and learn open-source contribution workflows.*

### 步骤 4：上传证明 (关键步骤)
系统会要求你开启摄像头拍照，或上传图片。
*   **拍照技巧**：确保光线充足，文字清晰可读。如果卡片反光，稍微倾斜角度。
*   **位置验证**：此时浏览器会弹出“请求获取位置信息”，**必须点击允许**。如果你的 IP 显示你在美国，但你申请的是中国的大学，会直接失败。

## 第三阶段：常见被拒原因与解决方案

申请提交后，如果收到 `Rejected` 邮件，通常是以下原因：

### 1. "You are significantly far from your campus"
*   **原因**：你的 IP 地址地理位置与学校所在地距离过远。
*   **解决**：
    *   最稳妥：连接学校 VPN 或在校内申请。
    *   如果不便返校，尝试使用手机流量（基站定位有时比宽带准），或者在申请说明中解释你在 "Remote Learning"（远程实习/网课），并提供相关证明。

### 2. "The image you uploaded is blurry" / "Unreadable"
*   **原因**：照片模糊或被系统识别为非原图。
*   **解决**：不要使用扫描件或屏幕截图。直接用手机摄像头拍摄实物，背景可以垫一张白纸，把学生证放在上面拍。

### 3. "Academic affiliation document does not contain a date"
*   **原因**：证明材料上没有当前日期。
*   **解决**：学生证如果没有注册章，请附上学信网的“在线验证报告”，或者去教务系统截一张包含“2024年春季学期”字样的课表，并用便签手写当天的日期放在旁边一起拍照。

## 常见问题 (FAQ)

**Q: 只有录取通知书可以申请吗？**
A: 可以，但通过率不如学生证。建议附加学费缴纳证明或入学系统的截图增加可信度。

**Q: 申请通过了，福利多久到账？**
A: 通常 1-3 天内会收到 Welcome 邮件，此时权益已生效。如果是人工审核，可能需要等待 1-2 周。

**Q: 毕业了还能用吗？**
A: 学生包有效期一般为 1-2 年。到期后如果仍在读，可以重新上传资料验证续期。毕业后权益会自动失效，但 GitHub 账号本身不受影响。
