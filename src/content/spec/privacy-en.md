### Tencent Video anime metadata requests

The anime page requests public ratings, descriptions, episode counts, update progress, and completion status for three predefined titles from this site's `/api/tencent-anime` endpoint. The endpoint only requests the corresponding public Tencent Video pages; it does not accept or proxy arbitrary third-party URLs, require a user login, or store personal information, search terms, or viewing history at the application layer. Responses are cached briefly. If Tencent Video is unavailable or does not return parseable data, the page keeps the site's default values.

This request passes through this site's deployment provider and Tencent Video. They may process standard connection logs, such as IP address, request time, and User-Agent, under their respective infrastructure policies.
