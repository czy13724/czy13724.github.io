# 腾讯视频动漫元数据

动漫页的评分、简介、集数、更新进度和完结状态来自腾讯视频的三部预设作品公开播放页。页面加载时调用本站接口，接口不会接收任意第三方 URL，也不会处理用户登录或观看记录。

## 更新频率

接口缓存最长 5 分钟。因此腾讯视频更新集数或状态后，页面会在下一次缓存刷新时同步，不需要手动修改 `src/data/anime.ts` 中的进度或状态兜底值。

## 本地验证

运行 Astro 开发服务器后，动漫页会通过开发期转接使用同一套接口逻辑。由于本站启用了尾斜杠，开发环境的接口地址为 `/api/tencent-anime/?id=xian-ni`；部署到 Vercel 后使用 `/api/tencent-anime?id=xian-ni`。

可在浏览器打开 `/anime/`，确认三张卡片的“进度”、状态标签和进度条已与接口返回内容同步。
