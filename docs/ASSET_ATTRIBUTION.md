# 素材来源

## 设备页照片

以下本地设备图片基于 Unsplash License 可免费使用的照片下载，并以 WebP 保存在 `public/images/device/`：

- `iphone17promax.webp`：Krzysztof Kowalik，Unsplash。
- `macbookairm4.webp`：Geio Tischler，Unsplash。
- `ipad2021.webp`：Microsoft Copilot，Unsplash。

其余设备卡片使用项目中既有的通用 Android 设备图片副本。它们用于设备分类展示，不应被理解为对应型号的官方产品图。

## 动漫和文章配图

动漫卡片封面使用腾讯视频当前提供的远程 CDN 图片；卡片会在远程封面缺失时自动显示 `public/images/anime/default-cover.svg` 与“暂无封面”。`public/images/content/` 的 SVG 为本项目自制图形。
