> "Data is the new oil, but privacy is the new gold."
> "数据是新时代的石油，但隐私是新时代的黄金。"

在这个抖音、小红书和 Twitter 算法主导信息流的时代，我们似乎越来越习惯于被动接受信息（Feed）。但作为一名技术爱好者，我始终认为：**拥有一个完全由自己掌控的独立博客（Independent Blog），是这个数字时代最酷的事情之一。**

今天，我想聊聊为什么我坚持维护这个基于 GitHub Pages 的博客，以及为什么你也应该尝试一下。

## 1. 数据的绝对掌控权

当你把文章发在知乎或公众号上，你的内容其实是属于平台的。平台可以因为“排版不规范”、“触犯敏感词”甚至仅仅是服务器故障，瞬间抹去你几年的心血。

但 GitHub Pages 不一样。
*   **代码即内容**：你的每一篇文章都是一个 `.md` 文件，实实在在地躺在你本地的硬盘里，同时也备份在 GitHub 的仓库中。
*   **版本控制**：借助 Git，你可以追溯每一个标点符号的修改历史。你可以随时回滚，而在中心化平台上，修改文章往往意味着“重新审核”。

## 2. 极客精神的绝佳实践场

搭建一个 GitHub Pages 博客，是你进入 Web 开发世界的最佳敲门砖。

*   **Jekyll/Hugo/Hexo**：你会接触到静态网站生成器 (SSG) 的概念，理解 HTML 是如何被“编译”出来的。
*   **CI/CD**：你会像大厂工程师一样，通过 GitHub Actions 配置自动化部署流程（比如我最近实现的[自动化图标仓库]({{site.baseurl}}/2026/01/24/GitHub-Actions-实战-打造全自动化的图标仓库/)）。
*   **Custom Domain**：当你把一串复杂的 IP 地址变成 `levifree.qzz.io` 这样优雅的域名时，那种成就感是无与伦比的。

## 3. 对抗信息碎片化

社交媒体鼓励短、平、快的内容。140 个字写不清逻辑，15 秒视频讲不透原理。

而写长文博客，是在训练你的**深度思考能力**。
当你要写一篇《Jekyll 主题修改教程》时，你必须把零散的知识点系统化；当你要记录一段生活感悟时，你必须诚实地面对自己的内心。

> "Writing is thinking."（写作即思考）

## 4. 建立被动连接 (Passive Networking)

我的博客经常会收到来自世界各地读者的 Email 或 Issue。
*   有人指出了我代码里的 Bug；
*   有人询问我关于 Mac 软件的推荐；
*   甚至有人因为看了我的文章邀请我参与开源项目。

这些连接是高质量的、跨越时空的。博客就像你在互联网上不知疲倦的数字分身，它在睡觉时也在向世界展示你的技能和价值观。

## 结语

搭建博客在技术上已经非常简单了，难的是**开始**，和**坚持**。

如果你还在犹豫，不妨现在就 Fork 一个喜欢的 Jekyll 主题（比如本站使用的 [Hux Blog](https://github.com/Huxpro/huxpro.github.io)），写下你的第一篇 `Hello World`。

种一棵树最好的时间是十年前，其次是现在。
